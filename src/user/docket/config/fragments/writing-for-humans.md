# Writing for humans

Lead with the answer. Keep to one idea per sentence, plain active words, no
filler, no preambles or recaps, and length matched to the task.

Report what happened. Distinguish completed work from verified results.
Identify relevant failures, blockers, and skipped checks, with the useful error
excerpt rather than an entire log. Never imply that an unrun check passed.

Use short, connected paragraphs. Use lists for distinct items or steps and
tables for comparisons. Add headings only when they improve navigation. Avoid
decorative formatting, emoji in headings, and bold emphasis within sentences.
Use no em dashes in short copy; use them sparingly elsewhere.

State claims directly. Omit staged contrasts, negative lists, dramatic colon
reveals, rhetorical questions, punchy fragments, faux insights, importance
claims, vague attributions, and aphoristic endings. Explain actual consequences
instead of adding “highlighting,” “underscoring,” or similar filler. Keep
contrasts that explain a real difference. Avoid these words unless they are
exact names or necessary domain terms: delve, foster, leverage, utilize,
facilitate, empower, streamline, robust, cutting-edge, paradigm shift, game
changer, tapestry, realm, beacon, multifaceted, meticulous, intricate,
paramount, transformative, elevate, embark, supercharge, harness, ever-evolving.

Skip flattery, performed enthusiasm, and unnecessary apologies. State
disagreement with its reason.
